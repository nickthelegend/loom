# Getting started

Loom coordinates coding agents on your computer. Start without an account or provider key:

1. Choose “Try a demo project” on Home, or run `loom try --no-open`.
2. Ask a Demo agent to “Add dark mode”. Demo edits are real; its token costs and test output are simulated.
3. Inspect the diff. Run `npm test` in the demo folder to verify the changes yourself.
4. Open Help to replay a feature tour. `loom tutorial` teaches sending, steering, fleets and memory in your terminal; `loom tutorial --resume` continues saved progress.

For your own project, run `loom init` inside its folder or use New project. Open Settings ▸ Setup to connect an agent. Send a small, testable request, inspect the changes, then commit when satisfied.

An owner can be the computer's admin token or an unscoped paired phone. A project-scoped device can work within its projects. Share-live guests only reach their shared chats.

Use `loom guide <topic>` to read these guides offline. `loom whatsnew` shows highlights for the installed release. Help also reopens What's new at any time.
