# Orchestra and fleets

Orchestra assigns a goal to an orchestrator and a fleet of workers. Enable Developer mode, open a project, choose Orchestra, select the orchestrator and at least two workers, then describe independent tasks and acceptance checks.

Workers use Git worktrees. Start from a clean repository and keep tasks focused. Watch the plan and task graph, reply to questions, and review the resulting diffs before landing changes. Budgets and worker limits are available in Orchestra options.

Try `loom try --scenario fleet --no-open` for a scripted, offline run. Home and phone Help have matching buttons. The demo uses only Demo agents and never calls a model provider.

Install the demo fleet with `loom examples install demo-team`; it names demo-2 and demo-3, so use it in the demo project. Replay the Orchestra tour from Help.
