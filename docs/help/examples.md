# Examples library

Home and phone Help offer bundled examples. `loom examples` lists them; `loom examples install <name>` installs one:

- small-change: a recipe to plan, implement and verify a focused change.
- demo-team: a fleet naming the demo project's two worker agents.
- daily-review: a daily project trigger, installed disabled for review.
- explain-code: a saved prompt template with a {{component}} variable.

Install is repeatable and preserves an existing example with the same name. Installation does not start a turn. Use the existing Recipes, Fleet, Triggers and Saved prompts surfaces to inspect and run what you installed.

Recipes, fleets and prompt templates are machine-wide and require an owner or unscoped paired device to install. Trigger examples belong to a project and can be installed by a token scoped to that project.
