# Brain and shared memory

Memory belongs to the project and is shared across its agents. Teach stable decisions and facts, including why they matter. Open Memory to inspect a memory's source, revise it or retire it when it becomes stale.

Relevant memories enter later turns through the briefing. A saved memory is not evidence that an agent used it: inspect the briefing and response. Keep secrets out of memory.

Try the offline scenario with `loom try --scenario memory --no-open`. One Demo agent teaches a release codename and another receives that decision in its briefing and answers using it. The decision persists in the project. You can also run the memory lesson in `loom tutorial`.

Replay the Brain tour from Help. “Show me” opens Memory on the web; phone Help explains the same steps.
