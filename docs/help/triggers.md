# Triggers and schedules

Triggers start prompts on a schedule or from a webhook. Open Triggers in a project. Set a clear prompt, choose an agent, then inspect the first resulting chat and run history.

`loom examples install daily-review` installs a daily review schedule into the current project, initially disabled. Review the prompt and agent choice before enabling it. Home and phone Help offer the same example library.

Use Run now to check behaviour. Pause a schedule when it is no longer useful. A webhook's secret belongs only to trusted callers; never paste it into shared chats.

Replay the Triggers tour from Help. “Show me” opens the project's Triggers panel.
