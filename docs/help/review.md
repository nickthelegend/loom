# Review changes with several agents

Open Source Control and choose Review. Select independent reviewers and a diff, file or text to inspect. Review turns are read-only. Findings include severity and location when available.

Compare the evidence rather than counting votes. Accept useful findings as decisions in shared memory, or reject them with a reason. Run your actual tests after implementing fixes.

Try `loom try --scenario review --no-open` to review a deliberately unsafe empty-list example with two offline Demo agents. The sample finding is scripted and clearly labelled; it is not a security audit of your project. No source files are edited by this review.
