## Loom 1.2.4: two machines, one goal, set up in one step

### Set up team auto-orchestration in one step
- **`loom team auto`** checks whether goals can split across your teammates' machines here. It says which of their agents a goal would get, and what's missing.
- **`loom team auto on`** does the setup:
  - shares the project;
  - writes `loom.team.json` if the repo has none (commit and merge it);
  - turns on your machine's shared runner, so teammates' goals can use your agents too.
- **The Team tab** shows the same status on a **Two machines, one goal** card, with a **Turn on** button.

### Steadier on a teammate's machine
- **A teammate's task no longer fails to commit.** Loom on their machine was saving its own end-of-turn checkpoint at the same moment and could undo the task's changes. The task's commit is now built separately, so nothing interferes.
- **Follow-ups reach the teammate.** When your orchestrator asks a teammate's task for more ("also fix the test"), their machine now gets that request on top of its earlier work, instead of the whole task again.
