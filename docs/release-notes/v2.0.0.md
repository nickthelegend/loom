## Loom 2.0: every agent, every model, as many as you want

Loom 2 turns one shared brain into a crew. Run two Claude Code on Opus next to two Codex on GPT‑5.6 in one Orchestra run, steer them mid-turn from your desk or your phone, see which model is actually winning, and let your agents drive Loom themselves. Someone who has never used it can now walk through the whole thing in two minutes, with no agent CLI and no API key. Ideas from [Agent Orchestrator](https://github.com/Untrivial-ai/agent-orchestrator) (Apache-2.0) and [T3 Code](https://github.com/pingdotgg/t3code) (MIT) are credited in THIRD_PARTY_NOTICES.md. How the feature set was chosen and where everything lives: [docs/v2/LOOM-2.md](https://github.com/nickthelegend/loom/blob/main/docs/v2/LOOM-2.md).

**Try it with nothing installed**
- **`loom try`** opens a demo project with three demo agents. They're scripted, offline and $0.00, and they make real edits and real diffs.
- **The walkthrough:** it sends a prompt, steers the running turn, opens Agents, and ends at Setup. You can also start it from **Try a demo project** on Home, in Setup, or in the phone's New project sheet.
- **Home**, with a **Get started** checklist that follows what you've really done.
- **One-click installs** for Claude Code, Codex and OpenCode in Setup, with no sudo.

**Every agent, every model, many times**
- **Fleets:** `-w claude-code@claude-opus-5-5x2,codex@gpt-5.6x2` in Orchestra, races, Ask several and chains. **Save a fleet** as `@squad` and reuse it anywhere.
- **Model scoreboard:** win rate from the picks you kept, finish rate, time and cost per turn, by agent + model or by model, per project or across all of them (`loom scoreboard`, ⌘K, or the ★ chip).
- **Ask several:** one prompt to several agents or models, side by side, each in its own worktree. Keep the best.
- **Per-chat and per-message model and effort**, and **steering** of a running Claude or Codex turn (⌥Enter, or long-press Send on the phone).
- **Several accounts per CLI:** when one hits its cap, Loom moves to the next account before it switches CLIs.

**Agents that drive Loom**
- **Loom skills:** `loom skills install loom` puts seven skills into Claude Code, Codex, OpenCode and Grok, and keeps them current. Your own skills are never touched. You can also use Settings ▸ Loom for agents.
- **Loom as an MCP server:** `loom mcp-server`, `POST /mcp` on the daemon, and `loom connect <agent>`. Fifteen `loom_*` tools let one agent start others on other models, message them, run an Orchestra and search the brain.
- Orchestra workers get the tools automatically, with a per-turn credential that can only read their project and use those tools.
- **Workers report as they go:** checkpoint, needs input, stuck, done.

**Chats that keep up**
- **Branches:** edit a prompt or retry a reply and flip between versions with ‹ 1/3 ›.
- **Side questions:** `/btw` asks without touching the thread.
- **Live presence** in shared chats.
- **Move a chat** to another of your machines.
- **Automatic chat titles.**
- **PRs that fix themselves:** CI failures and review comments go back to the chat that opened the PR. Comments come only from people with write access, and they're quoted as feedback.
- **My issues:** assigned GitHub and Linear issues become chats or Orchestra goals.
- **Open in editor:** VS Code, Cursor, Zed, JetBrains and more, from the Explorer and ⌘K. **`loom triage`** writes a redacted report for your agent.

**Your phone, from anywhere**
- New project, clone, or **Try a demo project**; **new chat with any agent on any model**; Get started; Triggers; a Terminal and a Files tab; saved fleets in Orchestra; steer with a long-press.

**Also in this release**
- The desktop Browser tab loads sites that refuse to be framed, in an isolated webview with real back and forward.
- ACP agents get the project's MCP servers.
- Security in review:
  - A cloned repo's own agent config is set aside rather than run.
  - Share-live guests can't pick a model or effort.
  - The terminal is refused to scoped tokens and guests.
  - The MCP tool credential can't change config, delete, add triggers, or add agents with options.
