## Loom 1.2.7: chains you can steer

- **`loom chain` takes run options:** `-o`, `-w`, `-p`, `--solo` and `--max-usd` apply to every line. A line can override them in brackets: `api :: [-o grok-code -w codex,opencode] add rate limiting`. Pick who plans each project's run instead of getting the default orchestrator.
- **`loom orchestra --json` always lists every task count,** with 0 when there are none.
