## Loom 1.1.2

**A working agent's row in the Fleet no longer spins over the row below it.**

The spinner's style applied to anything marked busy, not just the spinner. So
while an agent worked, its Fleet row shrank to a spinning dot, and its name,
"working" and permission chip spilled over the next row. The same thing
happened to the terminal's input while a command ran, the ✨ commit-message
button while it wrote a message, and busy nodes in the Observatory graph.
Now only the spinner spins.

Everything new in 1.1 is in the [1.1.0 notes](https://github.com/nickthelegend/loom/releases/tag/v1.1.0).

### Install

- **macOS**: the `arm64` (Apple silicon) or `x64` dmg below. The first time,
  right-click the app, choose Open, then Open. Or
  `brew upgrade --cask loom-desktop`.
- **Windows / Linux**: the installer for your platform below.
- **Android**: `loompad-1.1.2-android.apk` below.
- **CLI**: `npm install -g @loompad/cli`, then `loom up --restart`.
