# Loom Todos

A tiny, dependency-free todo app for exploring Loom. Serve this directory with
any static HTTP server and open index.html. Run the real tests with `npm test`.

Try asking a Demo agent:

- add dark mode
- add a todo filter
- write tests
- explain this repo

Demo agents are scripted, offline and free. They make real file edits, but their
command output and token counts are simulated. They never run shell commands.
Connect a real agent for work beyond these examples.
