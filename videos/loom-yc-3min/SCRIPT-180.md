# SCRIPT — Loom, 3 minute demo

## Line 1
    Every coding agent keeps its own memory, in its own files. Claude Code can't
    read what Codex knows. Switch tools, and you start over.

## Line 2
    Loom makes them one brain.

## Line 3
    Every agent, in one composer. And Loom asks each CLI what it can actually
    run — these are the real models Codex reported, not a list we typed in.

## Line 4
    One prompt into one shared thread. Claude Code plans it, the baton passes to
    Codex, and the context goes with it. Codex picks up mid-task and ships the
    code — a flag, and the test to cover it.

## Line 5
    Work moves on a board. Every task carries the agent that owns it, and when an
    agent finishes, the task moves itself.

## Line 6
    You decide who does what. Planner, builder, reviewer. You can switch any
    agent off — except the one holding the baton.

## Line 7
    And this is the part that matters. Twenty-one things this project has
    learned. Codex wrote that one. Antigravity wrote that one. Claude Code wrote
    those. Four different agents, one shared memory, and all of them can read
    all of it.

## Line 8
    The same brain is on your phone. Same thread, same agents, same baton — tap a
    chip and the work shifts while you're away from the desk.

## Line 9
    And we built it a body. The LoomPad is an open macropad — one key per agent.
    Press a key, hold the bar, speak. The fleet answers.

## Line 10
    It's fully open source. The enclosure, the wiring, the schematic — all of it
    is on GitHub. Print one, wire it, and it's yours.

## Line 11
    Think of it as a Codex Micro, but for every agent, in one device.

## Line 12
    Loom. One brain, every agent. Buy one soon, or build one yourself.
